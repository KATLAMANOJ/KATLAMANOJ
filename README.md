*Developed a high-performance Q&A and contract auditing assistant that automates legal document comprehension.*
* 🛠️ **Advanced RAG Pipeline**: Built a highly accurate Retrieval-Augmented Generation pipeline using **LangChain** and **Google Gemini 2.5 Flash API** to automate legal document Q&A.
* 🔍 **Semantic Search & Vector Store**: Processed contract text into 384-dimensional dense embeddings using `Sentence-Transformers` and indexed them via **FAISS** to enable sub-second similarity matching.
* 📦 **Optimized Chunking Strategy**: Engineered an ingestion workflow utilizing PyPDF loaders and `RecursiveCharacterTextSplitter` (300-character chunks, 80-character overlap) to maximize context preservation and prevent LLM hallucinations.
* 🖥️ **Interactive Dashboard**: Designed an interactive UI in **Streamlit** that supports multi-file PDF uploads and displays localized source citations for the top $K=3$ retrieved text segments.
